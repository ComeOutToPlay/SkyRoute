## Scope Discipline

The estimated challenge time is 3–4 hours.

Prioritize:
1. Correctness
2. Requirements coverage
3. Clean architecture
4. Tests for important business rules
5. Good UX
6. Documentation

Do not spend excessive time on:
- authentication
- deployment
- cloud infrastructure
- elaborate CI/CD
- unnecessary design patterns
- excessive abstractions
- features not requested by the challenge

If a feature is not required and would significantly increase implementation time, document it as a possible future improvement instead of implementing it.
